# Compact canonical per-gene trees

- `trees/<GENE>/`: final compact IQ-TREE output for each of BGN, EPYC, FMOD,
  LUM, OGN, and PRELP.
- `itol/`: corresponding iTOL tree and annotation files.
- `scripts/`: annotation helpers.
- `archive/`: the excluded 16-sequence chicken-BGN run and an OGN transition
  tree retained only for provenance.
